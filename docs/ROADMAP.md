# Roadmap

One GitLab milestone per phase. One issue per feature. New ideas go in a
"later" backlog issue, not the current phase.

- [x] Phase 0: Setup. Repo, CMake, window opens.
- [ ] Phase 1: Headless resolver. Card, ChainState, resolveChain(), 5 cards, console harness.
- [ ] Phase 2: Data and tests. cards.json loading, relic hooks, doctest.
- [ ] Phase 3: raylib prototype. Hand, drag into slots, Cast button.
- [ ] Phase 4: Rune tracing. Stroke capture, $1 recognizer, accuracy tiers.
- [ ] Phase 5: Combat loop. Enemy HP, intents, shield, draw/discard, turns.
- [ ] Phase 6: Run structure. Map, card rewards, shop, relics.
- [ ] Phase 7: Content and feel. About 30 cards, 15 relics, hidden techs, codex, sound.
- [ ] Phase 8: Optional release on itch.io.

## Rune tiers (design target)
- Under 85%: base value only, no penalty
- 85-95% (Resonant): bonus damage or better scaling
- 95%+ (Perfect): hidden tech
